# ADB 开启与使用

> 本文针对魔百盒 CM311-1（YST / S905L3 系）。运营商定制机的设置菜单**被改造过**，
> 路径与原生 Android 可能不同，本文给出排查顺序。

## 0. 先判断：也许已经开了

卖家固件**经常默认打开 ADB**。先探一下，别急着翻设置。

```powershell
adb connect <盒子IP>:5555
```

| 返回 | 含义 | 下一步 |
|---|---|---|
| `connected to <IP>:5555` | ✅ 已开启 | 直接用 |
| `connection refused` | ❌ 没开 | 见第 1 节 |
| `unable to connect` | ❌ 没开 / 不在同一局域网 | 检查网线、网段 |

盒子 IP 从**路由器后台**查。本机型**无 WiFi，必须有线**。

## 1. 从安卓设置里开启

**前提：盒子要接 HDMI 到显示器/电视**——开开发者选项必须看界面。

### 1.1 标准流程（Android 9 通用）

```
设置 → 关于 / 系统信息 / 版本信息
  ↓
找到「版本号」或「内部版本号」
  ↓
连点 7 次（提示"您已处于开发者模式"）
  ↓
返回 设置 → 开发者选项
  ↓
打开「USB 调试」
```

### 1.2 还需要更进一步的开关

只开「USB 调试」不一定能让 5555 端口监听。还要再找一个开关，**各厂商叫法不一**：

- 「网络调试」
- 「ADB 调试」
- 「无线调试」
- 「USB 调试（安全设置）」

**这几个名字里总有一个控制着 5555 监听，挨个试。**

## 2. 如果没有 5555 监听：用 USB 切到网络模式

`adb connect <IP>:5555` 的前提是盒子**已经在监听** 5555。
没监听的话，先用 **双公头 USB 线**接电脑切换：

```powershell
# 双公头 USB 线连接电脑与盒子（靠近网口的 USB 口）
adb devices
adb tcpip 5555        # 让盒子在 5555 端口监听
# 之后可以拔掉 USB 线
adb connect <盒子IP>:5555
```

> **所以双公头 USB 线不是废的**——在"启用网络 ADB"这一步用得上。

## 3. 运营商定制机：设置翻不动怎么办

魔百盒的设置被改造过，可能根本找不到「版本号」，或者点了没反应。

**办法 A：遥控器盲操**

有教程称**开机时用遥控器快速按「左键」或「菜单键」**可进入特定模式/菜单。免费，值得先试。

**办法 B：刷「默认打开 adb」的底包**

社区有现成的匹配固件，例如标题形如：

```
CM311-1_YST_S905L3(B)_安卓9.0_设置无密码_默认打开adb_..._线刷固件包
```

看名字就知道——**默认打开 adb**、**设置无密码**，正是为这种情况准备的。

**但这是线刷**，意味着要动双公头线 + Amlogic USB Burning Tool + 短接/免拆神器。
**属于"退一步"方案，先别急。**

## 4. ⚠️ ADB 不是必需的：TTL 可以替代

对本机型（**S905L3，无显示输出**），ADB 的定位要摆正：

| | ADB | TTL |
|---|---|---|
| 触发 U 盘/SSD 启动 | ✅ 方便 | ✅ 可控 |
| **能否看到启动发生了什么** | ❌ 屏幕无输出，全瞎 | ✅ **唯一能看的** |
| 需要盒子配合吗 | ✅ 需要 ADB 已开启 | ❌ 在 u-boot 层工作 |
| 需要开安卓设置吗 | ✅ 需要 | ❌ 不需要 |

**关键差别在后两行**：ADB 依赖安卓系统配合；
**TTL 直接挂在 u-boot 上，不关心安卓里开了什么。**

### 建议的优先级

```
① 先试 adb connect → 通了最省事
② 不通 → 翻设置开 ADB（需接 HDMI）
③ 设置也翻不动 → 直接走 TTL 引导，跳过 ADB
④ TTL 也不顺 → 才考虑刷「默认打开 adb」的底包
```

**第 ③ 步是对 ADB 的最大优势**——开不了 ADB **不等于**刷不了机。

## 5. 驱动与兼容性提示

- Android 平台工具走 **Google 官方源**：`https://dl.google.com/android/repository/platform-tools-latest-windows.zip`
- 在 Windows 11 上，ADB 本身通常**不需要**禁用驱动签名（**Amlogic USB Burning Tool 才需要**）
- 操作时可临时退出杀毒软件（尤其 360 类），它们可能拦截底层 ADB 通信

## 6. 常用命令速查

```powershell
adb version                    # 确认工具可用
adb connect <IP>:5555          # 网络连接
adb devices                    # 列出已连接设备
adb shell                      # 进盒子 shell
adb shell reboot update        # 触发从外部介质启动（具体命令因固件而异）
adb tcpip 5555                 # 切到网络 ADB 模式（需先 USB 连接）
adb disconnect                 # 断开
```
