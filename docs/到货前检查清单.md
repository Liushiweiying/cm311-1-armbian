## A. 显示通道分工（先搞清楚，别到货时误判）

| 设备 | 负责什么 | 用多久 |
|---|---|---|
| **电视 + HDMI** | **前期检查**：确认开机正常、看安卓信息、**开 ADB** | 一次性 |
| **TTL 串口** | **刷机全程**：启动日志、引导控制、判断卡在哪 | 全程 |
| **SSH** | 装完之后日常运维 | 长期 |

### ⚠️ 电视看不到刷机过程

| 阶段 | 电视显示 | 能否用它判断 |
|---|---|---|
| 安卓启动 | ✅ 正常 | ✅ 能 |
| 开 ADB（翻设置） | ✅ 正常 | ✅ **必须用** |
| 触发 U 盘/SSD 启动 | ⚠️ 黑屏或停 logo | ❌ 判断不了 |
| **Armbian 启动跑码** | ❌ **L3 不支持输出** | ❌ **看不到** |
| 进入 Armbian（server） | ❌ 无图形界面 | ❌ 看不到 |

**L3/L3B 不支持显示器显示启动信息**——这不是 HDMI 没插好，是芯片行为。
**别把电视当刷机时的观察窗。**

### 正确顺序：先 TTL，后电视

```
① 先接 TTL 上电抓日志 → 确认 gxl + L3/L3B + u-boot 可用
② 再接电视 → 确认机器状态、开 ADB
```

**理由**：TTL 不依赖安卓、不依赖盒子能否正常启动。
**盒子若有毛病，TTL 照样告诉你发生了什么，而电视只会给你一片黑。**

### ⚠️ 关于"不买免拆神器"

已决定不买。**这是合理取舍**，但要知道它意味着什么：

| 场景 | 没有免拆神器会怎样 |
|---|---|
| 主路径（TTL/ADB 引导 + 写 eMMC） | ✅ **完全不影响** |
| ADB 开不了，需刷「默认打开 adb」底包 | ⚠️ 需要短接，只能拆机用镊子 |
| 救砖 | ⚠️ 同上 |

**镊子短接有风险**：CoreELEC 文档明确警告——持续短接上电可能**熔锡、引脚永久焊连，eMMC 报废**。

**所以：主路径能走通就万事大吉；真需要线刷时再补买也来得及。**

## 红线速查

| 风险 | 可逆性 |
|---|---|
| **12V 电源极性插反** | ❌ **不可逆**（烧 PMIC/SoC） |
| 短接 eMMC 引脚失手 | ❌ **不可逆**（焊死引脚） |
| TTL 跳线设成 5V | ❌ 可能损坏 SoC UART |
| TTL 的 VCC 接到盒子 | ❌ 可能损坏 UART |
| bootloader / 分区刷坏 | ✅ 可救（线刷） |
| dtb 选错卡 logo | ✅ 可救（换镜像） |
| 刷到一半断电 | ✅ 可救（重新线刷） |

**软件层面基本刷不死**：Amlogic BootROM 烧在 SoC 硅片里，物理不可擦除。
**真正不可逆的只有电源极性和手工短接。**
