# 实战刷机流程（已跑通）

> 本文是**一次真实刷机的完整记录**，验证过的步骤。适合 CM311-1（S905L3 系）。
>
> 与 [`刷机操作手册_TTL+SSH.md`](刷机操作手册_TTL+SSH.md) 的区别：
> 那篇是**方案设计**，本篇是**实际执行的记录与坑**。

---

## 零、最终验证成功的路径（最短路线）

```
① 盒子跑安卓 + ADB 已开
② 写 Armbian 镜像到 U 盘（Rufus）
③ U 盘插盒子 → ADB 触发从 U 盘启动
④ 首次启动网络可能异常 → 重启一次
⑤ SSH 进去 → 备份 eMMC → armbian-install
```

**全程不需要**：双公头 USB 线、短接、免拆神器、TTL。

**⚠️ 但 TTL 仍是"保险"** —— 如果卡在引导阶段，只有串口能告诉你原因。

## 一、准备与工具选择

### 1.1 写盘工具的坑

| 工具 | 结果 |
|---|---|
| **balenaEtcher 2.1.7** | ❌ **安装成功但进程起不来**（Electron 在 Windows 上的常见问题） |
| **Rufus 4.15 便携版** | ✅ **直接可用，免安装** |

**建议直接用 Rufus：**

```
https://rufus.ie/downloads/
→ 选 Portable 版本（rufus-4.15p.exe，约 1.9 MB）
```

**Rufus 写入要点**：

| 项目 | 值 |
|---|---|
| 引导类型 | 选 `.img.gz` 文件本身（**文件类型过滤器改「所有文件」**） |
| 模式 | ⚠️ **DD 映像模式**（不是 ISO 模式） |
| 设备 | ⚠️ **仔细核对容量和卷标，别选到硬盘** |

### 1.2 ⚠️ 关于 Ventoy U 盘

**Ventoy 盘不能用。**

| 原因 | 说明 |
|---|---|
| 文件系统是 **exFAT** | Armbian 需要 FAT32 + ext4 |
| 分区布局不标准 | 盒子 u-boot 认不到 |

**要么另备一个 U 盘，要么备份 Ventoy 里的东西后覆盖它。**

**容量要求**：≥ 8GB（实测用 117GB 的盘也完全没问题，只是浪费）。

## 二、触发从 U 盘启动（ADB 路线）

### 2.1 前提

盒子跑安卓，且 **ADB 已开启**（商家定制的安卓 9.0 通常默认开）。

```powershell
cd <platform-tools 目录>
.\adb.exe connect <盒子IP>:5555
.\adb.exe devices          # 应显示 device
```

### 2.2 触发命令

```powershell
.\adb.exe shell reboot update
```

**执行后 ADB 会断开** —— 正常，盒子在重启。

**其他可尝试的命令**（如果 `update` 无效）：

```
adb shell reboot recovery
adb shell reboot bootloader
```

### 2.3 ⚠️ 命令生效了但看不到反馈

**盒子上没有任何提示。** 判断成功的唯一方式是**等它上线**。

## 三、⚠️ 最大的坑：首次启动网络异常

### 现象

**第一次 U 盘启动 Armbian 后，网络起不来：**

| 表现 | 结果 |
|---|---|
| 盒子 HDMI 显示正常（有开机横幅、shell 提示符） | ✅ 系统跑起来了 |
| **路由器「有线设备」列表为空** | ❌ **盒子没联网** |
| 网段扫描不到任何开放 22/5555 的设备 | ❌ |
| **ADB 也连不上** | ❌ 因为 ADB 是**安卓**的功能，Linux 下没有 adbd |

### 原因

**首次启动时 DHCP 没能拿到租约**（具体机制未深究），导致网络接口没配上 IP。

### ✅ 解决办法：**断电重启一次**

```
① 拔掉盒子电源
② 等 10 秒
③ 重新上电
④ 等 2–3 分钟
⑤ 路由器上出现新设备（设备名 armbian）
```

**实测：重启后网络正常，DHCP 拿到地址，SSH 立即可用。**

### 教训

> **首次 U 盘启动后没联网，先断电重启一次再排查别的原因。**

**这一条能省掉大量"盲猜"时间。**

## 四、首次启动的初始化

### 4.1 Armbian 首次运行会问三件事

屏幕上（或 SSH 里）会出现：

```
Create root password:              ← 设 root 密码（默认是 1234）
Repeat root password:

Choose default system command shell:
1) bash
2) zsh                             ← 选 1

Creating a new user account. Press <Ctrl-C> to abort
```

### 4.2 ⚠️ Linux 用户名的坑

**用户名不允许下划线 `_`！**

```
myuser_armbian    → ❌ Error: illegal characters in username
myuser-armbian    → ✅
myuserarmbian     → ✅
```

| 允许 | 不允许 |
|---|---|
| 小写字母、数字 | **下划线 `_`** |
| **连字符 `-`** | 大写字母、空格、点 |

**失败后它会提示 "Retrying on next login"，可以直接 Ctrl+C 跳过。**

### 4.3 建议：**跳过创建普通用户**

| 理由 | 说明 |
|---|---|
| 单人使用，不需要多用户 | |
| **root 直接用最省事** | 少一层 sudo |
| **随时能补** | 装完后 `adduser` 即可 |

**在 "Creating a new user account" 提示处按 `Ctrl + C`。**

## 五、⚠️ 备份原厂 eMMC（别省）

### 5.1 为什么必须做

| 原因 | 说明 |
|---|---|
| **L3 的安卓底包比 L3A 难找** | 万一想回退，这是唯一凭据 |
| **备份的是"原样"** | 所以刷机前**不要删应用、不要改系统** |
| **一次性的机会** | eMMC 被覆盖后就没了 |

### 5.2 操作

```bash
armbian-ddbr
```

**交互式脚本**，按提示选 `b`（backup）。

**产物位置**：`/ddbr/` 目录

```bash
ls -lh /ddbr/
```

### 5.3 ⚠️ 先确认空间够

```bash
df -h
lsblk
```

**参考实测**：

| 设备 | 典型值 |
|---|---|
| eMMC | `mmcblk2`，**14.6 GB** |
| eMMC 引导分区 | `mmcblk2boot0` / `boot1`，各 4MB |
| U 盘 | `sda`，根分区挂在 `/` |

**备份文件大小取决于实际数据量，一般 1–4 GB。**

### 5.4 ⚠️ 备份文件要拷出来

**备份存在 U 盘上。装完 eMMC 后这个 U 盘可能被重写 —— 记得先把备份拷到电脑。**

```powershell
# 在电脑上执行
scp root@<盒子IP>:/ddbr/backup.img <本地目录>\
```

## 六、写入 eMMC

```bash
armbian-install
```

**会出现机型选择菜单。**

**⚠️ 选择要点**：

| 要选 | 不要选 |
|---|---|
| `s905l3` | ❌ `s905l3a`（另一颗芯片） |
| | ⚠️ `s905l3b`（同平台但 dtb 不同，是备选） |

**装完后**：

```bash
poweroff
```

然后 **断电 → 拔 U 盘 → 重新上电**，应该从 eMMC 启动。

## 七、排错速查

| 现象 | 原因 | 处理 |
|---|---|---|
| `adb connect` 被拒绝 | ADB 没开 | 安卓设置里开；或改用 TTL |
| 触发后无反应 | 固件不支持该命令 | 试 `reboot recovery` / `reboot bootloader` |
| **启动后路由器上找不到盒子** | ⭐ **首次启动 DHCP 异常** | **断电重启一次** |
| 盒子 HDMI 正常但没网 | 同上 | 同上 |
| 网段扫描找不到 22 端口 | 网络没起来 | 同上；或看 HDMI 屏幕有无报错 |
| 卡在开机 logo | dtb 选错 | 换镜像（l3b / cm211） |
| 备份脚本报空间不足 | 目标盘满了 | 换大 U 盘或接外置盘 |

## 九、给下次的建议（如果还要刷一台）

```
① 直接准备 Rufus，跳过 balenaEtcher
② U 盘要 FAT32+ext4 结构（别用 Ventoy）
③ ADB 通就走 ADB 触发，省掉线刷那一套
④ ⭐ 首次 U 盘启动后没联网 → 先重启一次
⑤ 备份 eMMC 后立刻拷到电脑
⑥ TTL 备着，但不必卡在"找不到焊盘"上
```

**核心教训：把"能看见"和"能输入"这两件事优先解决。**
本次卡最久的两次，一次是"没网络"，一次是"没键盘"。
