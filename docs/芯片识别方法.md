# 芯片识别：怎么确认是 S905L3 还是 L3A

> 这是刷机前**最关键的一步**。选错芯片 = 选错镜像和 dtb = 开不了机。
>
> 本文记录一套**四层验证法**，从最不可信（外壳标签）到最可信（芯片丝印），
> 层层交叉印证。

---

## 为什么必须区分

`CM311-1` 和 `CM311-1a` 看着只差一个字母，**芯片完全不同**：

| 型号 | SoC | 平台家族 | CPU 核心 | 镜像 / 设备树 |
|---|---|---|---|---|
| **CM311-1** | S905L3 / L3B | **`meson-gxl`** | **Cortex-A53** | `meson-gxl-s905l2-x7-5g.dtb` |
| CM311-1a | S905L3A | `meson-g12a` | Cortex-A55 | `meson-g12a-s905l3a-cm311.dtb` |

**两者镜像、dtb、u-boot 引导文件完全不通用。**

---

## 四层验证法

### 第 1 层：外壳标签（最不可信）

看盒子底部标签的"产品型号"和"内存版本"。

| 标签写 | 倾向 |
|---|---|
| `CM311-1`（不带 a） | S905L3 / L3B |
| `CM311-1a` | S905L3A |

**⚠️ 不可信的原因**：二手市场存在贴错标签、换壳的情况。**只当线索，不当结论。**

---

### 第 2 层：ADB 读取系统属性（中等可信）

盒子跑安卓且 ADB 可用时：

```bash
adb shell getprop ro.board.platform
adb shell getprop ro.product.board
adb shell getprop ro.product.model
adb shell cat /proc/cpuinfo
```

**实战输出示例**：

```
ro.board.platform   = p291_iptv
ro.product.board    = p291_iptv
ro.product.model    = 11_CM311-1_2024
```

**怎么读**：

| 字段 | 含义 |
|---|---|
| `p291` | **Amlogic 板级参考设计名**，属于 **GXL 家族** |
| `g12a` | 如果看到这个，说明是 L3A 家族 |
| `CM311-1`（不带 a） | 型号正确 |

**⚠️ 不可全信的原因**：这些是**系统属性**，商家定制固件**可以改**。

---

### 第 3 层：CPU 核心型号（较可信）⭐

`/proc/cpuinfo` 里的 **CPU part 编号**是**内核实际报告的**，固件难以伪造：

| CPU part | 核心 | 对应芯片 |
|---|---|---|
| **`0xd03`** | **Cortex-A53** | **S905L3 / L3B** ✅ |
| `0xd05` | Cortex-A55 | S905L3A |
| `0xd07` | Cortex-A57 | — |

**实战输出**：

```
processor       : 0
CPU implementer : 0x41        ← ARM
CPU architecture: 7           ← ARMv7
CPU part        : 0xd03       ← Cortex-A53 ⭐
CPU revision    : 4

... (processor 1,2,3 同上，共 4 核)

Hardware        : Amlogic
```

**结论：4 × Cortex-A53 → 确定不是 L3A（L3A 是 A55）。**

**⚠️ 注意两个常见误读**：

| 现象 | 说明 |
|---|---|
| 显示 `ARMv7`（32 位） | **正常** —— 芯片本身是 64 位，但跑的是 32 位安卓用户空间 |
| 只有 4 个 processor | **正常** —— "八核"是商家话术（CPU 核 + GPU 核凑数） |

---

### 第 4 层：u-boot 日志 / 开机横幅（最可信）⭐⭐

**Armbian 启动后的开机横幅会自报硬件身份**：

```
Amlogic Meson GXL (S905L2) X7 5G Tv Box
```

| 关键字 | 含义 |
|---|---|
| **`GXL`** | ✅ **GXL 平台家族 → S905L3 系** |
| `g12a` | g12a 家族 → L3A |
| `X7 5G` | 对应设备树 `meson-gxl-s905l2-x7-5g.dtb` |

**⚠️ 关于 `S905L2` 这个标识**：这是**板级标识**，不代表真实芯片是 L2。
GXL 家族的多个板型（p281/x7/p291）共用相近的设备树。

---

## 交叉印证：三源一致才下结论

单看一条都可能被误导。**实战验证的正确做法**：

| 来源 | 实测结果 | 可信度 |
|---|---|---|
| 外壳标签 | `CM311-1`（无 a） | 🟡 |
| `ro.board.platform` | `p291_iptv` | 🟡 |
| **CPU part** | **`0xd03` = Cortex-A53** | 🟢 |
| **Armbian 开机横幅** | **`Amlogic Meson GXL ... X7 5G`** | 🟢 |

**四条独立证据全部指向 GXL / S905L3 系 → 结论确定。**

---

## ⚠️ 一个被广泛误传的说法

网上流传：**"S905L3/L3B 不支持显示器输出"**。

**实测：这是错的（至少对本板型）。**

| 阶段 | HDMI 实际表现 |
|---|---|
| 安卓启动 | ✅ 正常显示 |
| **从 U 盘启动 Armbian** | ✅ **正常显示** |
| **Armbian 跑起来后** | ✅ **正常显示**（含开机横幅、登录提示、shell） |

**不过**：内核启动参数里确实配的是 **串口为主控制台**：

```
console=ttyAML0,115200n8 console=tty0
```

- `ttyAML0` = **串口**（TTL）
- `tty0` = 虚拟终端（映射到 HDMI）

**所以串口和 HDMI 都有输出。** 但**早期 u-boot 阶段的日志可能只走串口** ——
如果卡在 u-boot 阶段，HDMI 可能看不到。

**结论**：HDMI 能看系统运行状态，但**排查引导阶段问题仍需 TTL**。

---

## 结论

### 本机最终身份

```
型号    : CM311-1（YST 代工 / 2GB+16GB / 无 WiFi / 12V 1A）
芯片    : Amlogic S905L3 系（GXL 家族）
CPU     : 4 × Cortex-A53
设备树  : meson-gxl-s905l2-x7-5g.dtb
镜像    : amlogic_s905l3
```

### 方法总结（可复用到其他 Amlogic 盒子）

```
① 看标签          → 线索
② ADB 读 getprop  → 缩小范围（p291/g12a）
③ 看 CPU part     → 确定核心架构（A53/A55）⭐
④ 看 u-boot/横幅  → 最终确认平台家族 ⭐
```

**②③④ 互相印证，结论才可靠。**
